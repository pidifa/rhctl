# What's New

## 📦 Repository Migration

- Transferred repository to pidifa: The rhctl repository has been transferred to the pidifa organization.

### Installation 🧰
#### Homebrew (macOS / Linux)
```bash
brew install saidake/rhctl/rhctl
```
#### Linux (x86_64)
```bash
# Download
curl -LO https://github.com/pidifa/rhctl/releases/download/v1.0.7/rhctl-v1.0.7-linux-x86_64

# Make executable
chmod +x rhctl-v1.0.7-linux-x86_64

# Move to /usr/local/bin
sudo mv rhctl-v1.0.7-linux-x86_64 /usr/local/bin/rhctl
```
