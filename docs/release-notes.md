# What's New

## 📦 Repository Migration

- A password is required when using sudo if the server does not allow passwordless sudo.

### Installation 🧰
#### Homebrew (macOS / Linux)
```bash
brew install pidifa/rhctl/rhctl
```
#### Linux (x86_64)
```bash
# Download
curl -LO https://github.com/pidifa/rhctl/releases/download/v1.0.8/rhctl-v1.0.8-linux-x86_64

# Make executable
chmod +x rhctl-v1.0.8-linux-x86_64

# Move to /usr/local/bin
sudo mv rhctl-v1.0.8-linux-x86_64 /usr/local/bin/rhctl
```
